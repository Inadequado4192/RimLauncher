# Changelog

## [v1.0.3] - 2025-09-16

### Added
- Added ability to split search by lists.
- Added ability to switch icon types (by type or custom icon).

### Changed
- Reduced UI size.
- Navigation through the list of modes has been slightly improved.
- Added support for Ctrl / Shift keys to select multiple modes.
- Attempt to improve startup performance.

### Fixed
- Improved error handling.


## [v1.0.2] - 2025-09-13

### Added
- Possibility to delete local mods

### Fixed
- Partially fix incorrect reading of Repo/User/Tree data when reading a git repository
- Minor improvements

## [v1.0.1] - 2025-09-07

### Fixes
- Updating modifications from git now works correctly.

## [v1.0.0] - 2025-09-05

🎉 Initial Release

First stable version of the project, ready to use.
